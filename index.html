⚡ Features

Everything you need to protect your privacy and boost productivity

🛡️

Ad & Tracker Blocking

Blocks 100,000+ ad and tracker domains using Edge's native declarativeNetRequest engine. No slowdown.

🔒

Site Lock & Vault

Protect any site behind a 4-digit PIN. Keep an extra-protected list of sensitive sites.

🎯

Focus Mode

Block distracting sites for a set period — only whitelisted sites remain accessible.

⏰

Time Limits

Set daily time caps on any domain. Get notified when you exceed the limit.

🔥

Emergency Burn

One click wipes history, cookies, and cache for non-protected sites. Fireproof sites are preserved.

🚨

Breach Alert

Check if your email has appeared in a data breach using haveibeenpwned.com's public API.

🧩

Tab Isolation

Prevent cross-site tracking between tabs — third-party cookies are blocked between tabs.

🎨

Element Picker

Right-click any element on any page and hide it permanently with a custom CSS rule.

📊

Weekly Report

See what's been blocked at a glance. Export reports as CSV for your own records.

🔐 Privacy by Design

Your data stays on your device — we never see it.

💾

Local Storage

All settings, whitelist, vault, PIN, and custom rules are stored locally in chrome.storage.local.

🚫

No Data Collection

We don't collect, store, or transmit any of your data. No backend servers. No tracking.

🔗

Filter Lists

Filter lists (EasyList, EasyPrivacy) are downloaded from public sources — no browsing data is sent.

📧

Breach Alert

Only the email you type is sent to haveibeenpwned.com's public API — never to us.
