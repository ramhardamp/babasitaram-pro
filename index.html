❓ अक्सर पूछे जाने वाले सवाल ❓ Frequently Asked Questions

क्या ये extensions मेरा data collect करते हैं?Do these extensions collect my data?
नहीं। BABASITARAM PRO कोई personal data, browsing history या analytics collect नहीं करता। सारा processing आपके browser के अंदर locally होता है — code 100% open source है, आप खुद verify कर सकते हैं। No. BABASITARAM PRO does not collect personal data, browsing history, or analytics. All processing happens locally in your browser — the code is 100% open source, so you can verify this yourself.
Passwords कहाँ store होते हैं?Where are passwords stored?
Password Manager आपके passwords को locally, आपके browser के encrypted storage में रखता है। ये कभी किसी external server पर नहीं भेजे जाते। The Password Manager stores your credentials locally in your browser's encrypted storage. Nothing is ever sent to an external server.
क्या ये Chrome पर भी काम करता है?Does this work on Chrome too?
हाँ। Extension GitHub Releases से manually install किया जा सकता है (Load Unpacked / drag-and-drop), साथ ही Firefox और Edge के official add-on stores पर भी उपलब्ध है। Yes. It can be manually installed on Chrome via GitHub Releases (Load Unpacked), and it's also available on the official Firefox and Edge add-on stores.
क्या ये free है?Is this free?
हाँ, पूरी तरह free और MIT licensed है। अगर पसंद आए तो नीचे दिए UPI QR से coffee के लिए support कर सकते हैं — ये पूरी तरह optional है। Yes, it's completely free and MIT licensed. If you like it, you can optionally support development via the UPI QR code below.
