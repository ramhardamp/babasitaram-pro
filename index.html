🔧 How to Install Offline in Chrome:

  1. ZIP फ़ाइल डाउनलोड करें और एक्सट्रैक्ट करें
  2. Download the ZIP file and extract it
  3. Chrome में chrome://extensions खोलें
  4. ऊपर दाएँ कोने में "Developer mode" ON करें
  5. Turn ON "Developer mode" in the top-right corner
  6. "Load unpacked" पर क्लिक करें और एक्सट्रैक्ट की गई फ़ोल्डर Select करें
  7. Click "Load unpacked" and select the extracted folder
  8. ✅ Extension Installed! अब यह हमेशा के लिए काम करेगा।
  9. ✅ Extension Installed! It will work permanently.
