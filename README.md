## 🌟 Why BABASITARAM PRO?

Most ad blockers stop at blocking ads. **BABASITARAM PRO** is a complete privacy **command center** — it blocks ads, kills trackers, guards your data, locks your browser, isolates your tabs, and burns your history — all in one extension.

| What others do | What BABASITARAM PRO does |
|---|---|
| Block ads on a page | Block ads + report per-site stats in real time |
| Let cookies pile up | Auto-wipe non-whitelisted cookies on idle |
| Forget about your history | Auto-delete non-whitelisted history |
| Nothing when you leave your desk | Lock ALL sites behind a PIN automatically |
| Show your email provider to every site | DNS-over-HTTPS (ISP blind mode) |
| No protection for your login sessions | Vault Mode — password-protect any site |
| No emergency option | 🔥 One-click Emergency Burn — wipes everything instantly |

## 🏗️ Architecture

### Why Two Background Files?

Chrome and Firefox handle MV3 backgrounds differently:

| | Chrome | Firefox |
|---|---|---|
| Background type | Service Worker | Event Page |
| `importScripts()` | ✅ Available | ❌ Not available |
| `getMatchedRules()` | ✅ Supported | ❌ Not implemented |
| Background file | `background.js` (Chrome build) | `background.js` (Firefox build) |
| AMO linter | Doesn't scan Chrome packages | Scans every file for flagged APIs |

Because AMO's static scanner flags `declarativeNetRequest.getMatchedRules` **by name** — even if it's behind a runtime check that never runs — the only solution is to **not include the string** in the Firefox package at all. The Firefox background achieves the same per-tab count from `trackerDomainStats` (already accumulated by the content script), so no functionality is lost.

### Filter Pipeline

```
EasyList.txt ──┐
EasyPrivacy.txt─┼──► filter-list-worker.js ──► DNR rules ──► chrome.declarativeNetRequest
uBO Annoyances─┘     (ABP → DNR parser)         (dynamic)
                      every 12 hours
```

### Message Bus

All popup ↔ background communication goes through `safeSendMessage()`:

```
popup.js
  └─ safeSendMessage(msg, cb)
       ├─ checks chrome.runtime.id (context invalidated guard)
       ├─ checks chrome.runtime.lastError (silent failure guard)
       └─ chrome.runtime.sendMessage → background.js handleMessage()
```

## 🔐 Privacy & Security

- **Zero data collection.** Nothing is sent to any server. Ever.
- **Zero telemetry.** No analytics, no crash reporting, no usage stats phoned home.
- **No account required.** All settings live in `chrome.storage.local` on your device.
- **Open source.** Read every line. Build it yourself. Audit it.
- **Breach Alert** makes direct API calls from your browser using *your own* API key. Your email never touches our servers.
- **HIBP API key** is stored in `chrome.storage.local` — not in code, not in sync storage, not in any server.
- All DOM construction uses `createElement`/`textContent` (zero `innerHTML` assignments in all production files).

## 🛠️ Building From Source

### Prerequisites

```bash
# macOS/Linux — bash + zip + python3 (for validation)
# Windows — use Git Bash or WSL
bash --version   # any version
zip --version
python3 --version
```

### Build

```bash
# Clone
git clone https://github.com/yourusername/babasitaram-pro.git
cd babasitaram-pro

# Build Chrome package → dist/chrome/ + babasitaram-pro-chrome.zip
bash scripts/build.sh chrome

# Build Firefox package → dist/firefox/ + babasitaram-pro-firefox.zip
bash scripts/build.sh firefox

# Build both
bash scripts/build.sh all

# Validate (lint + compliance check)
bash scripts/validate.sh
```

### Output

```
dist/
├── chrome/              # Unzipped — load unpacked in Chrome
│   ├── manifest.json
│   ├── background.js    # Chrome build (with getMatchedRules)
│   └── ... (all shared files)
│
├── firefox/             # Unzipped — load temporary in Firefox
│   ├── manifest.json
│   ├── background.js    # Firefox build (getMatchedRules removed)
│   └── ... (all shared files)
│
├── babasitaram-pro-chrome-9.2.4.zip   # → Chrome Web Store upload
└── babasitaram-pro-firefox-9.2.4.zip  # → Firefox AMO upload
```
