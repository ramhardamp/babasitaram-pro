## 🏗️ Architecture

### Why Two Background Files?

Chrome and Firefox handle MV3 backgrounds differently:

| | Chrome | Firefox |
|---|---|---|
| Background type | Service Worker | Event Page |
| `importScripts()` | ✅ Available | ❌ Not available |
| `getMatchedRules()` | ✅ Supported | ❌ Not implemented |
| Background file | `background.js` (Chrome build) | `background.js` (Firefox build) |
| AMO linter | Doesn't scan Chrome packages | Scans every file for flagged APIs |

Because AMO's static scanner flags `declarativeNetRequest.getMatchedRules` **by name** — even if it's behind a runtime check that never runs — the only solution is to **not include the string** in the Firefox package at all. The Firefox background achieves the same per-tab count from `trackerDomainStats` (already accumulated by the content script), so no functionality is lost.

### Filter Pipeline
EasyList.txt ──┐
EasyPrivacy.txt─┼──► filter-list-worker.js ──► DNR rules ──► chrome.declarativeNetRequest
uBO Annoyances─┘ (ABP → DNR parser) (dynamic)
every 12 hours

किसी आपात स्थिति में भरोसेमंद व्यक्ति तक पहुँच देने की व्यवस्था।
11. रिसाइकिल बिन (30 दिन)
ग़लती से डिलीट हुई एंट्री 30 दिन तक बिन में रहती है। चुनकर वापस लाएँ या हमेशा के लिए हटाएँ।
12. एक्टिविटी लॉग
तिजोरी में क्या-क्या हुआ, उसका रिकॉर्ड।
13. रिकवरी की
मास्टर पासवर्ड भूल जाने जैसी स्थिति के लिए रिकवरी की (PDF) बनाकर सुरक्षित रखें।
14. सुविधा के छोटे-बड़े साधन
होम स्क्रीन विजेट, क्विक सेटिंग्स टाइल, हिंदी और अंग्रेज़ी में हेल्प/FAQ।
Chrome और Firefox एक्सटेंशन
मोबाइल जैसा ही अनुभव कंप्यूटर पर भी।
• वेबसाइट पर लॉगिन फ़ील्ड में ऑटो-फिल सुझाव।
• नया या बदला पासवर्ड सेव/अपडेट करने का पॉप-अप, साथ में सुरक्षा जाँच ताकि कार्ड नंबर, CVV या छिपे हुए टोकन जैसी चीज़ें पासवर्ड समझकर सेव न हों।
• एक्सटेंशन के भीतर OTP कोड, कॉपी, एडिट और डिलीट।
• पासवर्ड मैनेजर पेज: पूरी लिस्ट, खोज, चयन, एडिट।
• पासवर्ड हिस्ट्री और एडिट हिस्ट्री: पुराना पासवर्ड कभी भी वापस देखें।
• QR कोड बनाएँ: एंट्री को मोबाइल पर आसानी से ले जाएँ।
• PIN से अनलॉक और ऑटो-लॉक।
• वॉल्ट हेल्थ, सुरक्षित शेयर लिंक, इमरजेंसी एक्सेस।
• ऐप और एक्सटेंशन का डेटा एक ही फ़ॉर्मेट (BSRPRO.Vault) में है, इसलिए एक से दूसरे में बैकअप जाता-आता है।
बैकअप, रीस्टोर और इम्पोर्ट
एन्क्रिप्टेड बैकअप
• एक ही फ़ाइल: BSRPRO.Vault (मास्टर पासवर्ड से एन्क्रिप्टेड)।
• ऑटो-बैकअप: रोज़ अपने आप, आपके चुने फ़ोल्डर में।
• नया फ़ोन: बैकअप फ़ोल्डर चुनें, वही मास्टर पासवर्ड डालें, और तिजोरी वापस। बिना डिलीट हुई, बिना नकल बनाए।
• ख़ाली तिजोरी से पुराना बैकअप कभी नहीं मिटता।
दूसरे ऐप से आसानी से आएँ
Chrome / Edge, Firefox, Bitwarden, LastPass, 1Password, Dashlane, NordPass, KeePass की CSV फ़ाइलें और vCard संपर्क इम्पोर्ट किए जा सकते हैं। फ़ाइल का प्रकार ऐप ख़ुद पहचान लेता है। इम्पोर्ट से पहले प्रीव्यू दिखता है और डुप्लीकेट छोड़े जाते हैं।
एक्सपोर्ट
एन्क्रिप्टेड .Vault, Chrome CSV, Bitwarden CSV, BSRPRO CSV या JSON में अपना डेटा कभी भी बाहर निकालें। आपका डेटा आपका है।
BSRPRO Vault किसके लिए?
• आम यूज़र: जो एक ही पासवर्ड हर जगह इस्तेमाल करते हैं।
• दुकानदार, CSC/ई-सेवा संचालक, फ्रीलांसर: जिनके पास कई पोर्टल और क्लाइंट अकाउंट हैं।
• परिवार और छोटे व्यवसाय: जिन्हें सुरक्षित शेयरिंग और इमरजेंसी एक्सेस चाहिए।
• ऐप और कंप्यूटर दोनों चलाने वाले: जिन्हें हर जगह एक जैसी तिजोरी चाहिए।
BSRPRO Vault क्यों चुनें?
1. एक मास्टर पासवर्ड, बाक़ी सब अपने आप।
2. मोबाइल + कंप्यूटर दोनों पर एक जैसा अनुभव।
3. OTP भी साथ में, अलग ऐप नहीं चाहिए।
4. आपका डेटा आपके पास, सर्वर पर अपलोड नहीं।
5. हिंदी में मदद और आसान इंटरफ़ेस।
6. पुराने ऐप से आसान बदलाव: CSV इम्पोर्ट से मिनटों में शिफ्ट।
शुरू कैसे करें? (3 आसान कदम)
1. ऐप इंस्टॉल करें और एक मज़बूत मास्टर पासवर्ड बनाएँ।
2. पुराने पासवर्ड इम्पोर्ट करें या नए सेव करें, और सेटिंग्स में BSRPRO Vault को ऑटोफिल सर्विस चुनें।
3. एक्सटेंशन जोड़ें और बैकअप फ़ोल्डर चुन लें।

अक्सर पूछे जाने वाले सवाल
क्या मेरा डेटा सर्वर पर जाता है? नहीं। तिजोरी आपके डिवाइस पर एन्क्रिप्टेड रहती है। इंटरनेट सिर्फ़ वैकल्पिक लीक-जाँच में इस्तेमाल होता है।
मास्टर पासवर्ड भूल गया तो? तिजोरी एन्क्रिप्टेड है, इसलिए मास्टर पासवर्ड के बिना खुल नहीं सकती। इसीलिए सेटअप के समय रिकवरी की बनाकर सुरक्षित रखें।
फ़ोन बदलने पर क्या होगा? बैकअप फ़ोल्डर चुनें और वही मास्टर पासवर्ड डालें, तिजोरी वापस आ जाएगी।
